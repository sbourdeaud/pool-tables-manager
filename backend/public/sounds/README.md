# Sounds Directory

This directory contains audio files for UI feedback.

## Required Files

- `pool-ball.mp3` - Sound played when:
  - A new table session starts
  - The eight ball logo in the header is clicked

## Adding the Sound File

Place your pool ball sound file as `pool-ball.mp3` in this directory.

The sound should be:
- Format: MP3
- Duration: Short (0.5-2 seconds recommended)
- Volume: Normalized to avoid being too loud

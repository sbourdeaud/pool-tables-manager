# Pool Tables Manager - 用户指南

## 欢迎使用 Pool Tables Manager

Pool Tables Manager 是一套全面的台球厅运营管理解决方案。本指南将帮助您了解并使用应用中的所有功能。

---

## 开始使用

### 访问应用

打开浏览器并访问 `http://localhost:3000`（或您的服务器地址）。

首次使用时，系统会要求您设置本地管理员密码（如果已配置密码/OIDC，则要求您登录）。登录后，仪表板会按类型显示所有球桌。

### 主菜单

页眉中有三个菜单项，此外还有主题切换按钮和退出登录按钮：

- **仪表板** - 实时查看球桌、时段和待处理订单
- **管理** - 菜单、球桌库存、订阅、报告和设置
- **公共状态** - 在新标签页中打开面向顾客的可用情况看板（无需登录）
- **帮助** - 应用内用户指南（本文档），含目录；还包括 API 参考链接
- **语言选择器** - 位于页眉（桌面端）、设置 → 本地化与定价、玩家球桌页面和公共状态看板中。所选语言会保存在当前设备上；饮品名称遵循菜单翻译（目前支持英语/法语）
- **退出登录**（右上角）- 结束管理员会话。启用 OIDC 时，如果身份提供商支持，也会同时结束其会话；随后返回登录页面

## 仪表板概览

仪表板是管理所有球桌的中心页面。

### 球桌显示

球桌按类型分组（美式、Pool、斯诺克、法式等），并以旗帜徽标和不同颜色的卡片显示：
- **绿色卡片** = 可用球桌
- **红色卡片** = 正在使用的时段
- 维护中的球桌不会显示在仪表板上（请在管理 → 球桌类型与库存中管理）

有两种布局可选（在**设置 → 仪表板布局**中选择）：

- **分组**（默认）— 所有类型按可折叠分组显示。顶部的**旗帜**可快速跳转（并展开）到对应类型；点击分组上的箭头可将其折叠。折叠状态会保存在当前设备上。
- **标签页** — 每个标签页显示一种球桌类型；拖动标签旁的**拖动手柄**即可调整标签顺序。

两种布局都支持调整球桌类型分组的顺序：在“分组”模式下，拖动分组标题左侧的 **⋮⋮ 拖动手柄**。顺序会保存并同步给所有员工设备，也会用于公共状态看板。

### 球桌信息

每张卡片显示：
- 球桌编号和类型
- 时段 PIN 码（时段进行中时显示）- 显示在球桌编号旁，例如“#5 (1234)”
- 当前时段时长
- 当前玩家人数
- 账单总额（累计费用）
- 快捷操作按钮

### 快捷操作

**可用球桌：**
- **开始时段** - 开始新的时段
- **维护** - 暂停使用该球桌（恢复使用时重置使用计数器）

**正在使用的球桌：**
- **饮品** - 将饮品添加到账单（按菜单类别分组）
- **转台** - 将时段转移到另一张球桌
- **结账** - 应用折扣、打印账单估算单、完成付款并打印发票
- 玩家人数旁的 **−** - 玩家结算（一名玩家支付其应付部分后离开）
- **+** - 添加玩家 — 系统会询问该玩家是否为订阅会员（会影响折扣）
- **二维码缩略图** - 放大玩家二维码

## 开始一个时段

1. 在可用球桌上点击 **▶ 开始**
2. 设置玩家人数（默认：1）
3. （可选）从列表中选择订阅会员
   - 订阅会员打球时可享受折扣；**仅订阅会员的时段也允许开始**（非订阅会员人数为 0），且免台费
   - 至少需要一名玩家（无论是否为订阅会员）
4. 点击 **开始时段**

**操作结果：**
- 系统为该时段生成唯一的 4 位 PIN 码
- 球桌会标记为正在使用
- 费用根据已用时长开始累计
- PIN 码会显示在球桌卡片上，供玩家查看账单

---

## 管理进行中的时段

### 实时更新

进行中的时段会显示：
- **时长** - 每秒更新（例如“1小时 23分 45秒”）
- **计费小时数** - 向上取整至整小时
- **账单总额** - 台费 + 商品费用

### 台费

台费按球桌类型以小时为单位计算：
- **美式台球：** €30/小时
- **Pool：** €25/小时
- **斯诺克：** €40/小时
- **法式台球：** €35/小时

时长始终向上取整至下一个整小时（例如：1小时1分钟按2小时计费）。

### 订阅会员折扣

订阅会员与非订阅会员一起打球时：
- **默认：** 台费五折
- **全部为订阅会员：** 免台费
- **没有订阅会员：** 全额收费

*可在设置中调整折扣比例。*

## 将商品添加到账单

### 快速添加饮品

1. 在正在使用的球桌卡片上点击 **饮品**
2. 浏览饮品菜单 — 使用**类别标签**（冷饮 / 热饮 / 含酒精饮品）和**搜索框**快速查找商品
3. 使用 **+** 和 **-** 按钮选择数量
4. 点击 **添加到账单**

### 自定义收费项目

在时段详情中：
1. 点击正在使用的球桌以查看详情
2. 滚动到“添加自定义收费”
3. 输入说明和金额
4. 点击 **添加收费**

**适用场景：**
- 食品
- 器材租赁
- 特殊费用
- 其他服务

## 待处理订单（玩家自助下单）

玩家可以通过手机访问[公共球桌视图](#public-table-view)，自行点饮品，无需员工走到球桌旁接单。

### 操作方式

1. 玩家在该球桌专属页面输入球桌的 **PIN 码**，并从菜单中选择饮品。
2. 订单提交后会立即显示在主仪表板顶部新建的**“待处理订单”**区域中，位于球桌网格上方。
3. 每当有新订单到达，管理员仪表板会播放提示音（“明亮三角铁”），员工无需一直盯着屏幕。
4. 每个待处理订单都会显示球桌编号、所点商品和总金额。
5. 员工核对订单，并在饮品送达后点击 **✓ 已完成**。
6. 完成订单后，订单中的商品会自动添加到该球桌的账单中，无需手动重新录入。

**安全性：** PIN 码验证可防止其他玩家或不在该球桌旁的人擅自向您的账单下单。

**声音提示：** 订单到达提示音遵循设置页面中的**声音提示**选项。

## 玩家结算

当一名玩家想要离开，而其他玩家继续打球时：

1. 在球桌卡片上点击 **🧾 结算**
2. 查看当前账单和台费
3. **选择台费选项：**
   - **玩家应付份额** - 由最初的玩家人数平均分摊
   - **全额台费** - 由该玩家支付全部台费
   - **不计台费** - 仅支付商品费用

4. **选择商品：**
   - 使用数量选择器勾选该玩家消费的商品
   - 可结算部分数量（例如：3 瓶啤酒中的 1 瓶）

5. 点击 **💰 结算**

**操作结果：**
- 所选商品会从账单中移除或减少数量
- 玩家人数减少 1 人
- 其他玩家的视图会自动更新
- 可以打印收据

**重要：** 结算金额以此前尚未扣除任何结算金额的*原始*台费为基准。

---

## 结束时段（结账）

所有玩家结束打球后：

1. 在球桌卡片上点击 **✓ 结账**
2. 核对最终费用：
   - 台费（根据时段总时长计算）
   - 账单中的所有商品
   - 之前的结算金额（显示为扣除项）
3. **可选：** 点击 **🖨 打印收据**以打印纸质收据
4. 点击 **结束时段**以完成操作

**操作结果：**
- 系统计算最终总额
- 时段标记为已完成
- 球桌恢复可用，可供下一时段使用
- 数据会保存，以供生成报告

## 公共球桌视图

玩家可以通过任何设备实时查看账单，也可以自行点饮品。

### 访问球桌视图

**URL 格式：** `http://[server]/table.html?number=[table_number]`

示例：`http://localhost:3000/table.html?number=5`

### 首次访问

1. 玩家访问该 URL
2. 输入 4 位 PIN 码（显示在仪表板上）
3. PIN 码会在本时段内保存

### 玩家可查看的信息

- 球桌编号和类型
- 当前时长
- 玩家人数
- 账单中的所有商品及其数量和价格
- 台费（小时数和金额）
- 当前累计总额
- 可直接点单的饮品菜单（需要 PIN 码）— 参见[待处理订单](#pending-orders-player-self-service)

**自动刷新：** 视图会自动刷新（约每 10 秒一次；切回该标签页时也会立即刷新），因此订单完成状态和账单变更会及时显示。

### 二维码

仪表板上每张正在使用的球桌卡片都会显示一个**二维码**，直接链接到该球桌的视图并预填 PIN 码。玩家只需用手机摄像头扫描即可查看时段，无需手动输入 URL 或 PIN 码。点击仪表板上的二维码可将其放大（便于打印或放在球桌旁展示）。

**设置二维码使用的主机名：** 默认情况下，二维码使用浏览器访问管理员仪表板时所用的地址（例如 `http://localhost:3000`），因此只能在同一台设备上使用。要让玩家用手机扫描二维码，请在管理 → 设置中设置**公共基础 URL**，填写手机实际可访问的主机名/IP 或 FQDN，例如 `http://[IP_ADDRESS]:3000` 或 `https://pool.example.com`。留空则使用当前浏览器地址。

## 管理员功能

通过菜单（☰）→ **管理面板**访问

### 球桌类型与库存

**管理球桌类型：**
- 添加新的球桌类型（例如“台球”“开伦”）
- 使用您的货币设置每小时费率
- 设置适用于该球桌类型台费的 **增值税税率**（20%、10% 或 0% — 参见[增值税 (TVA) 报告](#vat-tva-reporting--france)）
- 编辑或删除现有类型

**管理球桌：**
- **添加球桌：** 指定数量，即可一次创建多张球桌（自动连续编号）
- **重新编号：** 点击球桌编号旁的**铅笔**，输入新编号并按 Enter
  （如果该编号已被使用，系统会拒绝并显示说明）
- **删除球桌：** 删除未使用的球桌
- **设置维护模式：** 暂时停用球桌；恢复使用时会重置其
  自上次维护以来的使用计数器
- **排列类型顺序：** 使用每种类型旁的 **↑/↓** 按钮，更改仪表板、仪表板标签页/旗帜导航器和公共状态看板中的显示顺序

**批量操作：**
- 一次添加多张同类型球桌（1–50 张）
- 球桌会自动分配下一个可用编号

### 饮品菜单管理

1. 点击 **饮品菜单**
2. **添加新商品：**
   - 名称
   - 价格
   - 增值税税率（标准税率 20%、优惠税率 10% 或免税 0% — 参见[增值税 (TVA) 报告](#vat-tva-reporting--france)）
   - **类别** — 冷饮、热饮、含酒精饮品、其他（或不设类别）。类别会对玩家点单页面和仪表板的“添加饮品”对话框中的菜单进行分组。
3. **编辑/删除：** 使用每件商品旁的铅笔/垃圾桶按钮

**多语言支持：**
- 商品名称可设置英语和法语
- 可在设置中更改显示语言

### 付款（可选 POS）

付款功能默认**关闭**。请在**设置 → 常规 → “付款（POS）”**中启用（银行卡终端的设置方法另见[设置银行卡付款](#setting-up-card-payments-administrator)）。

启用后：

- **结账**会在开具发票前收款：
  - **现金：** 输入收到的现金并点击 **添加付款**（系统会显示找零）。使用**付清确切金额**即可恰好支付剩余余额。
  - **银行卡（终端）：** 点击 **银行卡（终端）— €X**。系统会显示“请在终端上刷卡……”提示；顾客轻触或插入银行卡后，付款会自动添加。点击**取消**可停止终端操作。
  - **分笔付款：** 添加多笔付款（现金和/或银行卡），直至剩余余额为零。仅当账单全额付清后，**完成结账**按钮才会启用。
  - 添加付款后将锁定折扣（防止金额发生偏差）。
- **收据**（屏幕显示和打印的发票）会列出付款方式及应找零金额。
- **管理 → 现金与付款**（仅在启用付款功能时显示）：
  - **现金班次：** 每日开始时以备用金开班；收班时输入盘点现金，系统会计算预期总额（备用金 + 现金净额）和**差额**。差额非零时会向已配置的维护邮箱发送邮件（需设置 SMTP）。
  - **退款：** 可对每笔付款退款，可部分退款并填写可选原因。已开具发票的付款退款时会生成带编号的**贷项通知单（avoir）**；提示消息中会显示其编号。
  - **贷项通知单：** 列表中提供**打印**按钮（会添加原始收据引用和增值税明细；可在打印对话框中另存为 PDF）。
  - **日结与对账：** 选择日期即可查看各付款方式的付款、贷项通知单，以及预期/盘点/差额现金金额；**导出 CSV**可下载付款明细账；**日结**会锁定该日（现金班次尚未结束时无法日结）。
- **报告 → 财务**会显示**现金/银行卡收款**和**退款（贷项通知单）**条目（PDF 和 Excel 导出中也包含这些信息）。**增值税 / TVA**报告会扣除贷项通知单，并显示*退款（贷项通知单）*类别。

### 设置

通过菜单（☰）→ **设置**访问

**可用设置：**

- **应用名称：** 页眉中显示的名称（例如“Joe's Pool Hall”）
- **公共基础 URL：** 生成球桌二维码时使用的主机名/IP 或 FQDN（参见[二维码](#qr-codes)）；留空则使用您当前浏览时所用的地址
- **仪表板布局：** 分组（可折叠分组 + 旗帜导航器）或标签页（每个标签页显示一种类型）
- **语言：** English、Français、Deutsch、Español 或 Italiano — 更改当前设备上的界面语言（也可在页眉、玩家球桌页面和公共状态看板中选择）
- **货币：** $ (USD)、€ (EUR) 或 £ (GBP)
- **订阅会员折扣：** 折扣百分比（0–100%）
- **声音提示：** 开启或关闭界面点击声和新订单提示音
- **财务/法律信息：** 企业法定名称、SIRET、SIREN、欧盟增值税号、注册地址、增值税制度和申报周期 — 用于增值税报告和内部记录（参见[增值税 (TVA) 报告](#vat-tva-reporting--france)）

**危险区域：**
- **清除所有时段历史记录：** 永久删除已完成的时段
  - 需要二次确认
  - 不会影响进行中的时段
  - **已关闭增值税申报期**内的时段也会受到保护，不会被删除

## 设置银行卡付款（管理员）

### 所需条件

- 应用通过 Docker 运行在可访问互联网的设备上。
- 一个 **Stripe 账户**（已验证企业信息）。请先使用**测试模式**。
- 一个 **Stripe Terminal 读卡器**（例如 WisePOS E），并已连接到场馆 Wi‑Fi；测试时也可使用 Stripe **模拟读卡器**。
- **Stripe 必须能够访问**您的服务器地址 `https://<your-domain>/api/webhooks/stripe`（公开 HTTPS、反向代理，或试运行期间使用隧道）。应用本身可继续在局域网内使用 HTTP。
- 仅收现金的场馆不需要这些条件：只需启用付款并使用现金即可。

### 操作步骤

1. **Stripe（测试模式）**
   - 配对/注册读卡器（Dashboard → Terminal → Readers）；记下其 ID（`tmr_…`）。
   - 在 Developers → Webhooks 中，添加 `https://<your-domain>/api/webhooks/stripe`，并订阅以下事件：
     `payment_intent.succeeded`、`payment_intent.payment_failed`、`payment_intent.canceled`；复制签名密钥（`whsec_…`）。
2. **服务器配置**（compose 环境 / `.env`），然后重启（`docker compose up -d`）：
   - `STRIPE_SECRET_KEY=sk_test_…`（之后换成正式密钥）
   - `STRIPE_TERMINAL_READER_ID=tmr_…`
   - `STRIPE_WEBHOOK_SECRET=whsec_…`
   - 应用通过 HTTPS 提供服务时设置 `COOKIE_SECURE=true`
3. **应用设置**
   - **设置 → 常规 → “付款（POS）” → 开启**。
   - 货币必须为 `€`、`$` 或 `£`（发送给 Stripe 时会转换为 eur/usd/gbp）。
   - 设置应用名称以及财务/法律信息（供报告和内部记录使用）。
   - 可选：设置 SMTP 和维护提醒邮箱，用于发送现金差额提醒。
4. **无需购买硬件即可测试**
   - 在环境中设置 `PAYMENT_PROVIDER=fake`：付款会立即完成（无需终端或网络）— 适合培训/测试界面。
   - 或使用 Stripe 测试模式和**模拟读卡器**，体验真实银行卡付款流程。
5. **正式启用前的试运行检查清单**
   - 现金销售的分笔付款和找零；银行卡付款；银行卡被拒后重试；在终端取消；部分退款（打印贷项通知单）；结束班次；日结并导出 CSV。
   - 试运行通过后再将 Stripe 切换到正式密钥。

### 故障排除与操作

- **未收到 Webhook**（终端显示已付款，但应用仍显示“正在等待刷卡”）：检查端点 URL、签名密钥和事件订阅；应用也会轮询付款状态，并在每次加载“现金”页面时重新同步过期的银行卡付款。如果付款已放弃，请在管理 → 现金与付款中点击该笔付款旁的**取消**。
- **日结卡片中的终端金额与应用金额不一致**：“终端（Stripe）”行来自 Stripe 余额交易（总额减退款，再加上显示的手续费）。请检查付款手续费显示、Stripe 仪表板中的退款，以及日结边界是否与您的会计日一致。只有在 Stripe 结算数据可用时才会显示该行。
- **快速停用付款功能：** 关闭**设置 → 常规 → “付款（POS）”** — 结账将恢复为启用 POS 之前的流程，银行卡选项会消失，“现金”页面也会隐藏。已有收据、贷项通知单和历史记录不受影响。
- **轮换密钥/读卡器：** 更新环境中的 `STRIPE_SECRET_KEY` / `STRIPE_TERMINAL_READER_ID` / `STRIPE_WEBHOOK_SECRET`，然后重启（`docker compose up -d`）。在 Stripe 仪表板中停用旧读卡器。
- **正式启用：** 将测试密钥/密钥替换为正式密钥，然后先用一笔小额真实付款重新执行试运行检查，再对外宣布支持银行卡付款。
- **仅收现金的场馆：** 无需配置 Stripe；启用付款并使用现金即可。班次、退款、贷项通知单、日结和 CSV 导出均可在没有终端的情况下使用。

### 注意事项

- **每个部署实例仅支持一个读卡器：** 读卡器 ID 在环境中配置。若需多个收银台，则需要选择读卡器的功能（目前尚未实现）。
- **依赖互联网连接：** 银行卡付款需要网络；若付款期间断网，状态可能会一直显示“正在等待刷卡” — 请在“现金”页面取消或退款。现金付款始终可用。
- **仅支持一个员工登录：** 目前应用只有一个管理员登录账户；付款/贷项通知单会记录该用户。
- **NF525（法国）：** 应用会以连续编号的收据记录销售和付款，并保存不可修改的明细、贷项通知单和申报期关闭记录 — 但认证是一项法律证明流程。宣传合规性或在正式环境启用银行卡付款前，请咨询您的 expert-comptable。
- 本功能集成的是**付款**，而不是外部酒吧 POS 系统（菜单/订单同步），也不支持顾客通过手机自行付款。

## 报告

通过**管理 → 报告**访问。页面包含两个标签页：**财务**和**增值税 / TVA**。

### 财务报告

生成任意时间段的详细收入报告。

**周期类型：**
- **日：** 指定日期，包含时段详情
- **周：** 从星期一开始的 7 天周期
- **月：** 完整日历月
- **季度：** 第 1、2、3 或 4 季度
- **年：** 年度汇总

**报告内容：**

1. **总收入** - 所有来源的收入合计

2. **按球桌类型统计的收入**
   - 美式台球：€X
   - Pool：€X
   - 斯诺克：€X
   - 法式：€X

3. **饮品/商品收入** - 食品和饮料销售额

4. **订阅收入** - 周期内有效订阅的收入

5. **时间序列分析**（周/月/季度/年报告）
   - 收入随时间的变化趋势
   - 按星期几分析
   - 识别高峰时段

6. **每日详情**（仅限日报）
   - 各时段明细
   - 按时段统计的球桌使用情况
   - 商品明细
   - 可编辑/删除收费项目

### 理解报告

**计入项目：**
- 已完成时段的台费
- 所有菜单商品和自定义收费项目
- 订阅收入

**不计入项目：**
- 正在进行的时段
- 结算会计分录（这些属于内部调整）
- 维护中或暂停使用的球桌

**自动加载：** 打开“报告”页面时会自动生成当天的报告。

## 增值税 (TVA) 报告 — 法国

> ⚠️ **这不是法律或税务建议。** 提交申报前，请咨询您的 *expert-comptable*，确认这些数据和流程符合您企业的具体增值税制度。完整的合规说明请参见 [VAT-COMPLIANCE.md](VAT-COMPLIANCE.md)。

“报告”页面中的**增值税 / TVA**标签页可用于准备定期增值税申报（CA3/CA12）。

### 生成增值税报告

1. 选择**周期类型**（月、季度、年或日）以及具体周期。
2. 点击**加载增值税报告**，查看按增值税税率划分的明细：
   - HT 总额（不含增值税）
   - TVA（增值税金额）
   - TTC 总额（含增值税）
3. 表格下方会显示按类别划分的明细（球桌时长、饮品、折扣、其他）。

### 关闭申报期

向税务机关提交某一申报期的申报后，点击**关闭申报期**。此操作将：
- 为记录保存该申报期的总额快照。
- 防止**清除所有时段历史记录**删除该申报期内的销售记录，确保已申报的数据始终可在数据库中追溯。

已关闭的申报期会显示在报告下方的历史列表中，其中包括周期、总额和关闭人。

### 导出文件供会计师使用

点击**导出 CSV 明细账**，即可下载所选周期内每一条销售明细（日期、球桌/时段、说明、数量、单价、增值税税率、增值税金额、不含税金额）— 方便交给会计师或长期归档。

### 确保增值税报告准确

- 在管理页面中为每种饮品和球桌类型设置正确的增值税税率（参见[饮品菜单管理](#drink-menu-management)和[球桌类型与库存](#table-types--inventory)）。
- **结束产生收入的时段时，始终使用“✓ 结账”→ 完成付款**，这样才能记录球桌时长费用并开具连续编号的收据。以其他方式结束时段会导致该台费未计入增值税报告。
- 在设置中填写您的**财务/法律信息**（SIRET、TVA 编号、增值税制度等），以便申报时查阅。

## 提示与最佳实践

### 日常运营

1. **营业开始时：**
   - 检查是否有异常遗留为“正在使用”状态的球桌
   - 查看昨天的报告
   - 确认所有球桌均设置为“可用”

2. **营业期间：**
   - 使用饮品快捷按钮提高操作速度
   - 玩家需要查看账单时，核对其 PIN 码
   - 留意持续时间较长的时段

3. **营业结束时：**
   - 为所有剩余时段结账
   - 生成日报
   - 检查是否存在问题或调整项

### 结算

- 结算前务必核对玩家人数
- 打印收据供顾客留存
- 仔细确认所选商品与玩家实际消费相符

### 确保准确

- 及时将商品添加到账单（不要等到结账时才添加）
- 菜单中没有的商品请使用自定义收费项目
- 开始时段时确认玩家人数正确

### 顾客服务

- 在时段开始后尽早将球桌 URL 分享给玩家
- 在球桌附近张贴二维码，方便顾客访问
- 介绍订阅会员福利，鼓励顾客注册

## 故障排除

### 常见问题

**“无法开始时段”**
- 检查球桌是否确实处于可用状态
- 确认订阅会员人数 ≤ 玩家总人数
- 刷新页面后重试
- 如果问题仍然存在，请联系管理员

**PIN 码无效**
- 确认 PIN 码与仪表板上显示的一致
- 检查球桌编号是否正确
- 时段结束后 PIN 码会失效

**商品没有显示在账单上**
- 确认商品已成功添加（查看成功提示）
- 等待约 10 秒以便公共视图自动刷新，或切回该标签页立即刷新
- 手动刷新仪表板

**显示的金额不正确**
- 确认货币设置正确
- 检查是否已应用结算
- 在时段详情中核对各项明细

### 获取帮助

如果问题仍然存在：
1. 记下球桌编号和发生时间
2. 尽可能截取屏幕截图
3. 联系系统管理员
4. 查看 Docker 日志（管理员操作）

## 常见问题

**问：时段开始后可以编辑吗？**
答：可以，您可以在时段进行期间添加/移除商品并调整玩家人数。

**问：如果我不小心结束了一个时段，会怎样？**
答：已结束的时段无法重新打开。您需要开始一个新时段。

**问：玩家可以自行添加商品吗？**
答：不可以，只有员工可以添加商品。玩家只能查看账单。

**问：如何处理免单时段？**
答：以 1 名玩家开始时段，添加商品，然后结账但不收款。

**问：可以在时段进行期间更改每小时费率吗？**
答：不可以，费率更改只对新时段生效。进行中的时段仍使用原费率。

**问：如果互联网断开怎么办？**
答：系统需要网络连接。进行中的时段会保留，但连接恢复前不会更新。

**问：可以导出报告数据吗？**
答：目前报告只能查看。您可以使用浏览器的打印/PDF 功能留存记录。

**问：可以查看多久以前的报告？**
答：只要时段历史记录仍然保留，就可以查看（直到您通过设置手动清除）。

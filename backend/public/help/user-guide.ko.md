# Pool Tables Manager - 사용자 가이드

## Pool Tables Manager에 오신 것을 환영합니다

Pool Tables Manager는 당구장 운영을 관리하기 위한 종합 솔루션입니다. 이 가이드는 애플리케이션에서 제공하는 모든 기능을 이해하고 사용하는 데 도움을 드립니다.

---

## 시작하기

### 애플리케이션 접속

웹 브라우저를 열고 `http://localhost:3000`(또는 서버 주소)로 이동합니다.

처음 접속하면 로컬 관리자 비밀번호를 설정하라는 메시지가 표시됩니다(비밀번호/OIDC가 이미 구성되어 있으면 로그인하라는 메시지가 표시됩니다). 로그인하면 대시보드에 유형별로 모든 테이블이 표시됩니다.

### 기본 메뉴

헤더에는 테마 전환과 로그아웃 버튼 외에 네 가지 메뉴 항목이 있습니다.

- **대시보드** - 실시간 테이블, 세션 및 대기 중인 주문
- **관리자** - 메뉴, 테이블 재고, 구독, 보고서 및 설정
- **공개 상태** - 고객용 이용 가능 현황판을 새 탭에서 엽니다(로그인 불필요).
- **도움말** - 목차가 포함된 앱 내 사용자 가이드(이 문서)이며 API 참조 링크도 포함합니다.
- **언어 선택기** - 헤더(데스크톱), 설정 → 현지화 및 요금, 플레이어 테이블 페이지 및 공개 상태 보드에서 사용할 수 있습니다. 선택한 언어는 기기에 저장되며, 음료 이름은 메뉴 번역을 따릅니다(현재 영어/프랑스어).
- **로그아웃**(오른쪽 상단) - 관리자 세션을 종료합니다. OIDC가 활성화되어 있고 지원되는 경우 ID 공급자 세션도 종료되며, 로그인 페이지로 돌아갑니다.

## 대시보드 개요

대시보드는 모든 테이블을 관리하는 중앙 허브입니다.

### 테이블 표시

테이블은 유형별(아메리칸, 풀, 스누커, 프렌치 등)로 그룹화되며, 깃발 배지와 색상으로 구분된 타일로 표시됩니다.
- **초록색 타일** = 사용 가능한 테이블
- **빨간색 타일** = 활성 세션
- 정비 중인 테이블은 대시보드에서 숨겨집니다(관리자 → 테이블 유형 및 재고에서 관리).

두 가지 레이아웃을 사용할 수 있습니다(**설정 → 대시보드 레이아웃**에서 선택).

- **섹션**(기본값) — 모든 유형을 접을 수 있는 그룹으로 표시합니다. **상단의 깃발**을 선택하면 해당 유형으로 이동하고 그룹이 펼쳐집니다. 그룹의 꺾쇠를 사용해 접을 수 있습니다. 접힌 상태는 이 기기에 저장됩니다.
- **탭** — 탭마다 테이블 유형 하나를 표시합니다. 탭 옆의 **잡기 핸들**을 드래그하여 탭 순서를 바꿀 수 있습니다.

두 레이아웃 모두에서 테이블 유형 그룹의 순서를 바꿀 수 있습니다. 섹션 모드에서는 그룹 제목 왼쪽의 **⋮⋮ 핸들**을 드래그합니다. 순서는 모든 직원 기기에 저장되며 공개 상태 보드에도 적용됩니다.

### 테이블 정보

각 타일에 표시되는 정보:
- 테이블 번호 및 유형
- 세션 PIN(활성 상태인 경우) - 테이블 번호 옆에 표시됩니다(예: "#5 (1234)").
- 현재 세션 시간
- 현재 플레이어 수
- 계산서 합계(누적 요금)
- 빠른 작업 버튼

### 빠른 작업

**사용 가능한 테이블:**
- **세션 시작** - 새 세션을 시작합니다.
- **정비** - 테이블 사용을 중단합니다(다시 사용 상태로 전환할 때 사용량 카운터를 초기화합니다).

**사용 중인 테이블:**
- **음료** - 계산서에 음료를 추가합니다(메뉴 카테고리별로 표시).
- **이동** - 세션을 다른 테이블로 옮깁니다.
- **계산** - 할인을 적용하고 계산서 예상액을 인쇄하며 결제를 완료하고 인보이스를 인쇄합니다.
- 플레이어 수 옆의 **−** - 플레이어 정산(플레이어 한 명이 본인 몫을 결제하고 나갑니다).
- **+** - 플레이어를 추가합니다. 구독자인지 묻는 메시지가 표시되며, 이는 할인에 영향을 줍니다.
- **QR 코드 미리보기** - 플레이어용 QR 코드를 확대합니다.

## 세션 시작

1. 사용 가능한 테이블에서 **▶ 시작**을 클릭합니다.
2. 플레이어 수를 설정합니다(기본값: 1명).
3. (선택 사항) 목록에서 구독자를 선택합니다.
   - 구독자는 플레이할 때 할인을 받습니다. **구독자만 참여하는 세션도 허용**되며(비구독자 0명), 테이블 이용료가 무료입니다.
   - 플레이어(구독자 여부 무관)가 한 명 이상 필요합니다.
4. **세션 시작**을 클릭합니다.

**진행되는 작업:**
- 세션에 고유한 4자리 PIN이 생성됩니다.
- 테이블이 사용 중으로 표시됩니다.
- 경과 시간에 따라 요금이 누적되기 시작합니다.
- 플레이어가 계산서를 확인할 수 있도록 PIN이 테이블 타일에 표시됩니다.

## 활성 세션 관리

### 실시간 업데이트

활성 세션에는 다음 정보가 표시됩니다.
- **시간** - 매초 업데이트됩니다(예: "1시간 23분 45초").
- **청구 시간** - 가장 가까운 시간 단위로 올림됩니다.
- **계산서 합계** - 테이블 요금 + 항목 요금

### 테이블 요금

요금은 테이블 유형에 따라 시간당 계산됩니다.
- **아메리칸 풀:** €30/시간
- **풀:** €25/시간
- **스누커:** €40/시간
- **프렌치 당구:** €35/시간

시간은 항상 다음 시간 단위로 올림됩니다(예: 1시간 1분 이용 시 2시간 요금 청구).

### 구독자 할인

구독자가 비구독자와 함께 플레이하는 경우:
- **기본값:** 테이블 요금 50% 할인
- **모두 구독자:** 요금 없음
- **구독자 없음:** 정상 요금

*할인율은 설정에서 조정할 수 있습니다.*

## 계산서에 항목 추가

### 음료 빠른 추가

1. 사용 중인 테이블 타일에서 **음료**를 클릭합니다.
2. 음료 메뉴를 살펴봅니다. **카테고리 버튼**(차가운 음료 / 따뜻한 음료 / 주류)과 **검색창**을 사용하면 항목을 빠르게 찾을 수 있습니다.
3. **+** 및 **-** 버튼으로 수량을 선택합니다.
4. **계산서에 추가**를 클릭합니다.

### 사용자 지정 요금

세션 상세 정보에서:
1. 사용 중인 테이블을 클릭해 상세 정보를 확인합니다.
2. "사용자 지정 요금 추가"까지 스크롤합니다.
3. 설명과 금액을 입력합니다.
4. **요금 추가**를 클릭합니다.

**사용 사례:**
- 음식 항목
- 장비 대여
- 특별 요금
- 추가 서비스

## 대기 중인 주문 (플레이어 셀프서비스)

플레이어는 직원이 테이블로 와서 주문을 받지 않아도 휴대전화의 [공개 테이블 보기](#public-table-view)에서 직접 음료를 주문할 수 있습니다.

### 작동 방식

1. 플레이어가 테이블 전용 페이지에서 테이블의 **PIN 코드**를 입력하고 메뉴에서 음료를 선택합니다.
2. 주문이 제출되면 메인 대시보드 화면 상단, 테이블 그리드 위에 새 **"대기 중인 주문"** 섹션이 표시되고 주문이 즉시 나타납니다.
3. 새 주문이 도착할 때마다 관리자 대시보드에서 차임벨("밝은 트라이앵글")이 울리므로 직원이 화면을 계속 지켜보지 않아도 됩니다.
4. 각 대기 주문에는 테이블 번호, 주문 항목 및 합계가 표시됩니다.
5. 직원이 주문을 확인하고 음료를 전달한 뒤 **✓ 제공 완료**를 클릭합니다.
6. 주문을 제공 완료 처리하면 해당 항목이 테이블 계산서에 자동으로 추가되므로 직접 다시 입력할 필요가 없습니다.

**보안:** PIN을 요구하므로 다른 플레이어나 테이블에 없는 사람이 해당 계산서에 주문을 추가할 수 없습니다.

**오디오 신호음:** 주문 도착 차임벨은 설정 페이지의 **오디오 신호음** 설정을 따릅니다.

## 플레이어 정산

다른 플레이어는 계속 플레이하지만 한 플레이어가 먼저 나가려는 경우:

1. 테이블 타일에서 **🧾 정산**을 클릭합니다.
2. 현재 계산서와 테이블 요금을 확인합니다.
3. **테이블 요금 옵션 선택:**
   - **플레이어 몫** - 처음 플레이어 수를 기준으로 균등 분할합니다.
   - **테이블 요금 전체** - 플레이어가 테이블 요금 전액을 부담합니다.
   - **테이블 요금 건너뛰기** - 항목 요금만 결제합니다.

4. **항목 선택:**
   - 수량 선택기를 사용해 플레이어가 소비한 항목을 선택합니다.
   - 일부 수량만 정산할 수 있습니다(예: 맥주 3잔 중 1잔).

5. **💰 정산**을 클릭합니다.

**진행되는 작업:**
- 선택한 항목이 계산서에서 삭제되거나 수량이 줄어듭니다.
- 플레이어 수가 1명 줄어듭니다.
- 남은 플레이어의 화면이 자동으로 업데이트됩니다.
- 영수증을 인쇄할 수 있습니다.

**중요:** 정산 금액은 이전 정산이 적용되기 전의 *최초* 테이블 요금을 기준으로 합니다.

## 세션 종료 (계산)

모든 플레이어가 이용을 마쳤을 때:

1. 테이블 타일에서 **✓ 계산**을 클릭합니다.
2. 최종 요금을 확인합니다.
   - 테이블 요금(총 이용 시간 기준)
   - 계산서의 모든 항목
   - 이전 정산 내역(차감액으로 표시)
3. **선택 사항:** 종이 사본이 필요하면 **🖨 영수증 인쇄**를 클릭합니다.
4. **세션 종료**를 클릭해 완료합니다.

**진행되는 작업:**
- 최종 합계가 계산됩니다.
- 세션이 완료로 표시됩니다.
- 다음 세션을 위해 테이블을 사용 가능 상태로 전환합니다.
- 보고서용 데이터가 저장됩니다.

## 구독

### 구독이란?

구독은 테이블 요금 할인을 제공하는 선불 회원권입니다.

### 구독 확인

1. 메뉴(☰)를 엽니다.
2. **구독**을 클릭합니다.
3. 다음 정보가 포함된 활성 구독을 확인합니다.
   - 플레이어 이름
   - 시작 날짜
   - 종료 날짜
   - 현재 상태

### 구독 사용

세션을 시작할 때:
1. 플레이어 수를 설정합니다.
2. 구독자 이름 옆의 체크박스를 선택합니다.
3. 시스템이 자동으로 할인을 적용합니다.

**혜택:**
- 테이블 요금 할인 또는 면제
- 분석을 위한 사용 내역 추적
- 단골 고객 유도

## 공개 테이블 보기

플레이어는 모든 기기에서 실시간으로 계산서를 확인하고 직접 음료를 주문할 수 있습니다.

### 테이블 보기 접속

**URL 형식:** `http://[server]/table.html?number=[table_number]`

예: `http://localhost:3000/table.html?number=5`

### 처음 접속하는 경우

1. 플레이어가 URL로 이동합니다.
2. 4자리 PIN을 입력합니다(대시보드에 표시됨).
3. PIN이 해당 세션 동안 저장됩니다.

### 플레이어에게 표시되는 정보

- 테이블 번호 및 유형
- 현재 이용 시간
- 플레이어 수
- 수량 및 가격을 포함한 계산서의 모든 항목
- 테이블 요금(시간 및 금액)
- 누적 합계
- 메뉴에서 직접 주문할 수 있는 음료 목록(PIN 필요) — [대기 중인 주문](#pending-orders-player-self-service) 참조

**자동 새로고침:** 화면은 약 10초마다, 그리고 해당 탭으로 돌아올 때 즉시 자동으로 새로고침되므로 제공 완료된 주문과 계산서 변경 사항이 빠르게 표시됩니다.

### QR 코드

대시보드의 모든 활성 테이블 타일에는 PIN이 미리 입력된 해당 테이블 보기로 바로 연결되는 **QR 코드**가 표시됩니다. 플레이어는 휴대전화 카메라로 코드를 스캔해 세션을 확인할 수 있으며 URL이나 PIN을 직접 입력할 필요가 없습니다. 대시보드에서 QR 코드를 클릭하면 확대할 수 있습니다(인쇄하거나 테이블에 표시할 때 편리합니다).

**QR 코드에 사용할 호스트 이름 설정:** 기본적으로 QR 코드는 관리 대시보드를 불러올 때 브라우저에서 사용한 주소(예: `http://localhost:3000`)를 가리키며, 이는 같은 기기에서만 작동합니다. 플레이어의 휴대전화로 QR 코드를 스캔할 수 있게 하려면 관리자 → 설정의 **공용 기본 URL**에 휴대전화에서 접속할 수 있는 호스트 이름/IP 또는 FQDN을 설정합니다(예: `http://[IP_ADDRESS]:3000` 또는 `https://pool.example.com`). 비워 두면 현재 브라우저 주소를 사용합니다.

## 관리자 기능

메뉴(☰) → **관리자 패널**에서 접속합니다.

### 테이블 유형 및 재고

**테이블 유형 관리:**
- 새 테이블 유형 추가(예: "당구", "캐롬")
- 사용할 통화로 시간당 요금 설정
- 해당 테이블 유형의 이용 시간 요금에 적용할 **VAT 세율** 설정(20%, 10% 또는 0% — [VAT (TVA) 보고](#vat-tva-reporting--france) 참조)
- 기존 유형 수정 또는 삭제

**테이블 관리:**
- **테이블 추가:** 한 번에 여러 테이블을 만들 수량을 지정합니다(번호가 순차적으로 자동 부여됨).
- **번호 변경:** 테이블 번호 옆의 **연필**을 클릭하고 새 번호를 입력한 다음 Enter를 누릅니다(이미 사용 중인 번호는 설명 메시지와 함께 거부됩니다).
- **테이블 삭제:** 사용하지 않는 테이블을 삭제합니다.
- **정비 모드 설정:** 테이블을 일시적으로 비활성화합니다. 테이블을 다시 사용하도록 전환하면 정비 이후 사용량 카운터가 초기화됩니다.
- **유형 순서 지정:** 각 유형의 **↑/↓** 버튼으로 대시보드, 대시보드 탭/깃발 탐색기 및 공개 상태 보드에 표시되는 순서를 변경합니다.

**일괄 작업:**
- 동일한 유형의 테이블을 여러 개 추가합니다(한 번에 1~50개).
- 테이블에는 사용 가능한 다음 번호가 자동으로 지정됩니다.

### 음료 메뉴 관리

1. **음료 메뉴**를 클릭합니다.
2. **새 항목 추가:**
   - 이름
   - 가격
   - VAT 세율(표준 20%, 인하 10% 또는 면세 0% — [VAT (TVA) 보고](#vat-tva-reporting--france) 참조)
   - **카테고리** — 차가운 음료, 따뜻한 음료, 주류, 기타(또는 없음). 카테고리는 플레이어 주문 화면과 대시보드의 "음료 추가" 대화상자에서 메뉴를 그룹화합니다.
3. **수정/삭제:** 각 항목 옆의 연필/휴지통 버튼을 사용합니다.

**다국어 지원:**
- 항목 이름은 영어와 프랑스어로 입력할 수 있습니다.
- 표시 언어는 설정에서 변경할 수 있습니다.

### 결제 (선택적 POS)

결제 기능은 **기본적으로 꺼져 있습니다**. **설정 → 일반 → “결제 (POS)”**에서 활성화합니다(카드 단말기는 [카드 결제 설정](#setting-up-card-payments-administrator)도 참조).

활성화하면:

- **계산**은 인보이스 발행 전에 결제 금액을 받습니다.
  - **현금:** 받은 현금을 입력하고 **결제 추가**를 클릭합니다(거스름돈이 표시됩니다). 잔액을 정확히 결제하려면 **정확한 금액**을 사용합니다.
  - **카드(단말기):** **카드(단말기) — €X**를 클릭합니다. "단말기에 카드를 대세요…" 배너가 표시되고, 고객이 카드를 대거나 삽입하면 결제가 자동으로 추가됩니다. **취소**를 누르면 단말기 작업이 중단됩니다.
  - **분할 결제:** 잔액이 0이 될 때까지 여러 결제(현금 및/또는 카드)를 추가합니다. 계산서가 전액 결제된 경우에만 **계산 완료**가 활성화됩니다.
  - 결제가 추가되면 할인이 잠깁니다(금액 변동 방지).
- **영수증**(화면 및 인쇄된 인보이스)에는 결제 수단과 거스름돈이 표시됩니다.
- **관리자 → 현금 및 결제**(결제 기능이 활성화된 경우에만 표시):
  - **현금 시프트:** 하루를 시작할 때 시작 준비금과 함께 시프트를 엽니다. 마감할 때 실사한 현금을 입력하면 예상 합계(준비금 + 순현금)와 **차액**이 계산됩니다. 차액이 0이 아니면 SMTP가 설정된 경우 구성된 정비 담당 주소로 이메일이 전송됩니다.
  - **환불:** 결제 건별로 환불하며 금액을 지정할 수 있습니다(부분 환불 가능). 사유는 선택 사항입니다. 인보이스가 발행된 결제를 환불하면 번호가 매겨진 **크레디트 노트 (avoir)**가 발행되며 알림에 번호가 표시됩니다.
  - **크레디트 노트:** **인쇄** 버튼과 함께 표시됩니다(원본 영수증 참조 및 VAT 내역 포함, 인쇄 대화상자에서 PDF로 저장 가능).
  - **일일 마감 및 대사:** 날짜를 선택하면 결제 수단별 결제, 크레디트 노트, 예상/실사 현금 및 차액을 확인할 수 있습니다. **CSV 내보내기**는 결제 원장을 다운로드하며, **일일 마감**은 해당 날짜를 잠급니다(현금 시프트가 열려 있으면 마감할 수 없습니다).
- **보고서 → 재무**에는 **현금/카드 결제** 및 **환불(크레디트 노트)** 행이 표시됩니다(PDF 및 Excel 내보내기에도 포함). **VAT / TVA** 보고서는 크레디트 노트를 차감하고 *환불(크레디트 노트)* 카테고리를 표시합니다.

### 설정

메뉴(☰) → **설정**에서 접속합니다.

**사용 가능한 설정:**

- **애플리케이션 이름:** 헤더에 표시되는 이름(예: "Joe's Pool Hall")
- **공용 기본 URL:** 테이블 QR 코드 생성에 사용할 호스트 이름/IP 또는 FQDN ([QR 코드](#qr-codes) 참조). 비워 두면 현재 접속 중인 주소를 사용합니다.
- **대시보드 레이아웃:** 섹션(접을 수 있는 그룹 + 깃발 탐색기) 또는 탭(탭마다 유형 하나)
- **언어:** English, Français, Deutsch, Español 또는 Italiano — 이 기기의 인터페이스를 변경합니다(헤더, 플레이어 테이블 페이지 및 공개 상태 보드에서도 선택 가능).
- **통화:** $ (USD), € (EUR) 또는 £ (GBP)
- **구독자 할인:** 할인율(0~100%)
- **오디오 신호음:** UI 클릭 소리와 새 주문 차임벨 켜기/끄기
- **세무/법적 정보:** 법적 사업자명, SIRET, SIREN, TVA 역내 거래 번호, 등록 주소, VAT 제도 및 신고 주기 — VAT 보고서와 자체 기록에 사용됩니다([VAT (TVA) 보고](#vat-tva-reporting--france) 참조).

**위험 구역:**
- **모든 세션 기록 삭제:** 완료된 세션을 영구적으로 삭제합니다.
  - 두 번 확인해야 합니다.
  - 활성 세션에는 영향을 주지 않습니다.
  - **마감된 VAT 기간**에 포함된 세션도 보호되며 삭제되지 않습니다.

## 카드 결제 설정 (관리자)

### 필요한 항목

- 인터넷에 접속할 수 있는 기기에서 실행 중인 앱(Docker)
- **Stripe 계정**(사업자 정보 확인 완료). **테스트 모드**로 시작합니다.
- 매장의 Wi‑Fi에 연결된 **Stripe Terminal 리더기**(예: WisePOS E) 또는 테스트용 **Stripe 시뮬레이션 리더기**
- **Stripe가** `https://<your-domain>/api/webhooks/stripe`에서 서버에 접속할 수 있어야 합니다(공개 HTTPS, 리버스 프록시 또는 시험 운영 중 터널 필요). 앱 자체는 LAN 내부에서 HTTP로 실행해도 됩니다.
- 현금만 받는 매장에는 이 설정이 필요하지 않습니다. 결제 기능을 활성화하고 현금을 사용하면 됩니다.

### 단계

1. **Stripe(테스트 모드)**
   - 리더기를 페어링/등록합니다(대시보드 → Terminal → Readers). 리더기 ID(`tmr_…`)를 기록합니다.
   - Developers → Webhooks에서 `https://<your-domain>/api/webhooks/stripe`를 추가하고 다음 이벤트를 설정합니다.
     `payment_intent.succeeded`, `payment_intent.payment_failed`, `payment_intent.canceled`; 서명 시크릿(`whsec_…`)을 복사합니다.
2. **서버 구성**(compose 환경 변수 / `.env`)을 마친 다음 재시작합니다(`docker compose up -d`).
   - `STRIPE_SECRET_KEY=sk_test_…`(나중에 라이브 키로 교체)
   - `STRIPE_TERMINAL_READER_ID=tmr_…`
   - `STRIPE_WEBHOOK_SECRET=whsec_…`
   - 앱을 HTTPS로 제공할 때는 `COOKIE_SECURE=true`
3. **앱 설정**
   - **설정 → 일반 → “결제 (POS)” → 켜기**
   - 통화는 `€`, `$` 또는 `£`여야 합니다(Stripe로 eur/usd/gbp가 전송됩니다).
   - 애플리케이션 이름과 세무/법적 정보를 설정합니다(보고서 및 자체 기록에 사용).
   - 선택 사항: 현금 차액 알림을 위한 SMTP 설정 및 정비 알림 이메일
4. **하드웨어 구매 없이 테스트**
   - 환경 변수에 `PAYMENT_PROVIDER=fake`를 설정하면 결제가 즉시 처리됩니다(단말기와 네트워크 불필요). UI 교육/테스트에 적합합니다.
   - 또는 Stripe 테스트 모드와 **시뮬레이션 리더기**를 사용해 실제 카드 결제 흐름을 테스트합니다.
5. **실서비스 전 시험 운영 점검표**
   - 현금 분할 결제 및 거스름돈, 카드 결제, 카드 거절 후 재시도, 단말기에서 취소, 부분 환불(크레디트 노트 인쇄), 시프트 마감, 일일 마감 및 CSV 내보내기를 확인합니다.
   - 시험 운영을 통과한 후에만 Stripe 라이브 키로 전환합니다.

### 문제 해결 및 운영

- **웹훅이 도착하지 않음**(단말기에는 결제가 표시되지만 앱에는 "제시 중"으로 표시됨): 엔드포인트 URL, 서명 시크릿 및 이벤트 구독을 확인합니다. 앱은 결제 상태를 폴링하며 현금 페이지를 불러올 때 오래된 카드 결제도 다시 동기화합니다. 결제가 중단된 경우 관리자 → 현금 및 결제에서 해당 결제 옆의 **취소**를 누릅니다.
- **일일 마감 화면의 단말기와 앱 합계가 다름:** "단말기(Stripe)" 행은 Stripe 잔액 거래(총액에서 환불을 뺀 금액과 표시된 수수료)를 기준으로 합니다. 결제 수수료 표시, Stripe 대시보드의 환불, 일일 마감 경계가 회계상 하루의 경계와 일치하는지 확인합니다. Stripe 정산 데이터가 있을 때만 이 행이 표시됩니다.
- **결제 기능을 빠르게 끄기:** **설정 → 일반 → “결제 (POS)”**를 끕니다. 계산은 POS 이전 방식으로 돌아가고 카드 옵션이 사라지며 현금 페이지가 숨겨집니다. 기존 영수증, 크레디트 노트 및 기록은 그대로 유지됩니다.
- **키/리더기 교체:** 환경 변수의 `STRIPE_SECRET_KEY` / `STRIPE_TERMINAL_READER_ID` / `STRIPE_WEBHOOK_SECRET`을 업데이트하고 재시작합니다(`docker compose up -d`). Stripe 대시보드에서 이전 리더기 사용을 중지합니다.
- **실서비스 전환:** 테스트 키/시크릿을 라이브 값으로 교체한 다음, 카드 결제를 공지하기 전에 소액의 실제 결제로 시험 운영 점검표를 다시 확인합니다.
- **현금 전용 매장:** Stripe 설정은 필요하지 않습니다. 결제 기능을 활성화하고 현금을 사용하면 됩니다. 시프트, 환불, 크레디트 노트, 일일 마감 및 CSV 기능은 단말기 없이 모두 사용할 수 있습니다.

### 알아둘 사항

- **배포 환경당 리더기 한 대:** 리더기 ID는 환경 변수에 설정됩니다. 여러 계산대에서 사용하려면 리더기 선택 기능이 필요하지만 현재 구현되어 있지 않습니다.
- **인터넷 연결 필요:** 카드 결제에는 연결이 필요합니다. 결제 중 연결이 끊기면 결제가 "제시 중" 상태로 남을 수 있습니다. 현금 페이지에서 취소/환불하세요. 현금 결제는 항상 사용할 수 있습니다.
- **직원 로그인 계정 하나:** 현재 앱에는 관리자 로그인 계정이 하나뿐이며 결제/크레디트 노트에는 해당 사용자가 기록됩니다.
- **NF525(프랑스):** 앱은 순차 영수증, 변경 불가 항목, 크레디트 노트 및 기간 마감을 사용해 매출과 결제를 기록합니다. 다만 인증은 법적 확인 절차입니다. 규정 준수를 광고하거나 운영 환경에서 카드 결제를 활성화하기 전에 expert-comptable와 확인하세요.
- 이 기능은 **결제**를 연동하며, 외부 바 POS(메뉴/주문 동기화)나 고객의 휴대전화 셀프 결제는 지원하지 않습니다.

## 보고서

**관리자 → 보고서**에서 접속합니다. 페이지에는 **재무**와 **VAT / TVA** 두 개의 탭이 있습니다.

### 재무 보고서

원하는 기간의 상세 매출 보고서를 생성합니다.

**기간 유형:**
- **일:** 세션 상세 정보가 포함된 특정 날짜
- **주:** 월요일에 시작하는 7일 기간
- **월:** 전체 달력 월
- **분기:** Q1, Q2, Q3 또는 Q4
- **연도:** 연간 요약

**보고서 내용:**

1. **총 매출** - 모든 수입원을 합산한 금액

2. **테이블 유형별 매출**
   - 아메리칸 풀: €X
   - 풀: €X
   - 스누커: €X
   - 프렌치: €X

3. **음료/항목 매출** - 음식 및 음료 판매

4. **구독 매출** - 해당 기간의 활성 구독

5. **시계열 분석**(주/월/분기/연도 보고서)
   - 시간에 따른 매출 추세
   - 요일별 분석
   - 이용량이 가장 많은 시간대 파악

6. **일별 상세 정보**(일 보고서만 해당)
   - 개별 세션 내역
   - 세션별 테이블 사용량
   - 항목별 상세 정보
   - 요금 수정/삭제 기능

### 보고서 이해하기

**포함 항목:**
- 완료된 세션의 테이블 요금
- 모든 메뉴 항목 및 사용자 지정 요금
- 구독 매출

**제외 항목:**
- 활성(진행 중인) 세션
- 정산 회계 항목(내부 조정 내역)
- 정비 중이거나 일시 중지된 테이블

**자동 불러오기:** 보고서 페이지를 열면 당일 보고서가 자동으로 생성됩니다.

## VAT (TVA) 보고 — 프랑스

> ⚠️ **법률 또는 세무 자문이 아닙니다.** 신고하기 전에 *expert-comptable*와 상담하여 이 수치 및 절차가 사업체의 VAT 제도에 맞는지 확인하세요. 전체 적합성 참고 사항은 [VAT-COMPLIANCE.md](VAT-COMPLIANCE.md)를 참조하세요.

보고서 페이지의 **VAT / TVA** 탭에서 정기 VAT 신고서(CA3/CA12)를 준비할 수 있습니다.

### VAT 보고서 생성

1. **기간 유형**(월, 분기, 연도 또는 일)과 해당 기간을 선택합니다.
2. **VAT 보고서 불러오기**를 클릭하면 세율별 내역이 표시됩니다.
   - 합계 HT(VAT 제외)
   - TVA(VAT 금액)
   - 합계 TTC(VAT 포함)
3. 카테고리별 내역(테이블 이용 시간, 음료, 할인, 기타)이 표 아래에 표시됩니다.

### 기간 마감

세무 당국에 해당 기간의 신고서를 제출한 뒤 **기간 마감**을 클릭합니다. 다음 작업이 수행됩니다.
- 기록을 위해 해당 기간의 합계를 스냅샷으로 저장합니다.
- **모든 세션 기록 삭제** 작업으로 해당 기간의 매출을 삭제할 수 없게 하여 신고 수치를 데이터베이스에서 항상 추적할 수 있도록 합니다.

마감된 기간은 보고서 아래의 기록 목록에 표시되며 기간, 합계 및 마감한 사용자를 확인할 수 있습니다.

### 회계사에게 자료 내보내기

**CSV 원장 내보내기**를 클릭하면 선택한 기간의 개별 판매 항목(날짜, 테이블/세션, 설명, 수량, 단가, VAT 세율, VAT 금액, HT 금액)을 모두 다운로드합니다. 회계사에게 전달하거나 장기 보관할 때 편리합니다.

### VAT 보고서 정확하게 유지하기

- 관리자에서 각 음료와 테이블 유형의 VAT 세율을 올바르게 설정합니다([음료 메뉴 관리](#drink-menu-management) 및 [테이블 유형 및 재고](#table-types--inventory) 참조).
- 매출이 발생한 세션을 종료할 때는 **항상 "✓ 계산" → 결제 완료**를 사용합니다. 이 방법으로 테이블 이용 시간 요금이 기록되고 순차 영수증이 발행됩니다. 다른 방법으로 세션을 종료하면 해당 테이블 이용 시간 요금이 VAT 보고서에서 누락됩니다.
- 설정의 **세무/법적 정보**(SIRET, TVA 번호, VAT 제도 등)를 입력해 신고 시 확인할 수 있도록 합니다.

## 유용한 팁 및 모범 사례

### 일상 운영

1. **영업 시작 시:**
   - 사용 중으로 남아 있는 테이블이 있는지 확인합니다.
   - 전날 보고서를 검토합니다.
   - 모든 테이블이 "사용 가능"으로 설정되어 있는지 확인합니다.

2. **영업 중:**
   - 빠른 음료 버튼을 사용해 시간을 절약합니다.
   - 플레이어가 계산서에 접속하려는 경우 PIN을 확인합니다.
   - 오래 진행 중인 세션을 살펴봅니다.

3. **영업 종료 시:**
   - 남아 있는 모든 세션을 계산합니다.
   - 일일 보고서를 생성합니다.
   - 문제나 조정 내역을 검토합니다.

### 정산

- 정산 전에 항상 플레이어 수를 확인합니다.
- 고객 기록용 영수증을 인쇄합니다.
- 선택한 항목이 플레이어가 소비한 내역과 일치하는지 다시 확인합니다.

### 정확한 기록

- 항목은 계산서에 바로 추가합니다(계산 시점까지 미루지 않습니다).
- 메뉴에 없는 항목에는 사용자 지정 요금을 사용합니다.
- 세션을 시작할 때 플레이어 수가 맞는지 확인합니다.

### 고객 서비스

- 세션 초반에 플레이어와 테이블 URL을 공유합니다.
- 쉽게 접속할 수 있도록 테이블 근처에 QR 코드를 게시합니다.
- 구독 신청을 유도할 수 있도록 구독 혜택을 안내합니다.

## 문제 해결

### 일반적인 문제

**"세션을 시작할 수 없습니다"**
- 테이블을 실제로 사용할 수 있는지 확인합니다.
- 구독자 수가 전체 플레이어 수보다 많지 않은지 확인합니다.
- 페이지를 새로고침한 뒤 다시 시도합니다.
- 문제가 계속되면 관리자에게 문의합니다.

**PIN이 작동하지 않음**
- 대시보드의 PIN과 일치하는지 확인합니다.
- 테이블 번호가 올바른지 확인합니다.
- 세션이 종료되면 PIN이 만료됩니다.

**계산서에 항목이 표시되지 않음**
- 항목이 추가되었는지 확인합니다(성공 메시지를 확인하세요).
- 공개 화면의 경우 자동 새로고침까지 약 10초 기다리거나, 즉시 새로고침하려면 해당 탭으로 돌아갑니다.
- 대시보드를 수동으로 새로고침합니다.

**금액이 잘못 표시됨**
- 통화 설정이 올바른지 확인합니다.
- 정산이 적용되었는지 확인합니다.
- 세션 상세 정보에서 개별 항목을 검토합니다.

### 도움말 얻기

문제가 계속되면:
1. 테이블 번호와 발생 시간을 기록합니다.
2. 가능하면 스크린샷을 찍습니다.
3. 시스템 관리자에게 문의합니다.
4. 관리자라면 Docker 로그를 확인합니다.

## 자주 묻는 질문

**질문: 세션을 시작한 뒤에도 수정할 수 있나요?**
답변: 예. 세션 중 항목을 추가/삭제하고 플레이어 수를 조정할 수 있습니다.

**질문: 실수로 세션을 종료하면 어떻게 되나요?**
답변: 종료된 세션은 다시 열 수 없습니다. 새 세션을 시작해야 합니다.

**질문: 플레이어가 직접 항목을 추가할 수 있나요?**
답변: 아니요. 항목 추가는 직원만 할 수 있습니다. 플레이어는 계산서만 확인할 수 있습니다.

**질문: 무료 세션은 어떻게 처리하나요?**
답변: 플레이어 1명으로 세션을 시작하고 항목을 추가한 다음, 요금을 청구하지 않고 계산을 완료합니다.

**질문: 세션 중간에 시간당 요금을 변경할 수 있나요?**
답변: 아니요. 요금 변경은 새 세션에만 적용됩니다. 활성 세션에는 처음 설정한 요금이 적용됩니다.

**질문: 인터넷이 끊기면 어떻게 되나요?**
답변: 시스템에는 네트워크 접속이 필요합니다. 활성 세션은 유지되지만 연결이 복구될 때까지 업데이트가 일시 중지됩니다.

**질문: 보고서 데이터를 내보낼 수 있나요?**
답변: 현재 보고서는 보기 전용입니다. 기록이 필요하면 브라우저의 인쇄/PDF 기능을 사용하세요.

**질문: 얼마나 오래된 보고서까지 볼 수 있나요?**
답변: 세션 기록이 보존되는 동안 확인할 수 있습니다(설정에서 수동으로 삭제할 때까지).

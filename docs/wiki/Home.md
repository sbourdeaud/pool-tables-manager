- **Help** menu in the application (`/help`) renders the User Guide with a table of contents.
- **API reference** at `/api-docs` on your installation is an interactive Swagger UI (OpenAPI spec at
  [`backend/public/openapi.json`](https://github.com/sbourdeaud/pool-tables-manager/blob/master/backend/public/openapi.json)).
